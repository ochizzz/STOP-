# СТОП! Симулятор тупейшего патрульного

Мобильная HTML5-игра без сборки и зависимостей: открой `index.html` на телефоне или в браузере.

## Экраны
- **🗺️ Карта** (круглая кнопка в центре) — нарисованный город с районами: Центр, Свадебный квартал, Гусиный парк, Колхоз «Заря». На перекрёстках появляются задания в виде предупреждающих знаков ⚠️: тапни, прочитай условие, заступай на смену.
  - Сбоку: 🎁 ежедневная премия, 📋 задания дня, 🚓 свободная смена (бесконечный режим), 📻 рация (новые вызовы).
- **🛒 Магазин** — бустеры (эвакуатор, сирена, пончик, аптечка), улучшения, сундук «Конфискат».
- **👕 Гардероб** — шапка, форма, жезл. Примерка до покупки.
- **⚙️ Настройки** — звук, вибрация, эффекты, подсказки, номер патруля, сброс.
- **🏆 Рейтинг** — статистика и доска почёта.

## Игра
- Тап по дороге — туда едут, остальные стоят. Две дороги сразу = ДТП.
- Водители злятся (😄→🤬): прорываются на красный или едут прямо в тебя.
- Скорая, свадебные кортежи, клоун-кары, коровы, гуси, тракторы, автобусы.
- Задания: продержаться N секунд, набрать очки, пропустить скорые/коров/кортежи, смена без ДТП, ночная смена.

## Файлы
- `index.html` — разметка экранов
- `css/style.css` — стиль
- `js/data.js` — районы, транспорт, задания, магазин, гардероб
- `js/game.js` — движок перекрёстка
- `js/app.js` — карта, вкладки, прогресс (localStorage)
