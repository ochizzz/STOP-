# СТОП! Симулятор тупейшего патрульного

Мобильная HTML5-игра на один файл (`index.html`), без зависимостей. Открой на телефоне или в браузере.

- Тап по дороге — туда едут машины, остальные стоят.
- Стоящие водители звереют: прорываются на красный или сбивают тебя.
- Две пересекающиеся дороги разом = ДТП. 3 жизни.
- Скорая, свадебный кортеж, клоун-кар, коровы, гуси, трактора, таксисты.
- Силы: 🪄 жезл дзена (обнуляет гнев в одном направлении, перезарядка), 🏗 эвакуатор, 🚨 сирена, 🍩 пончик. Премии каждые 400 очков.
