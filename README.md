# STOP! — регулировщик

Мобильная игра (Android, iOS через Capacitor) про регулирование дорожного движения: low-poly 3D, вид сверху.

## Как играть
- Стрелка у каждой стороны перекрёстка: зелёная — поток едет, жёлтая — готовится к остановке, красная — стоит.
- Свайп по стороне к центру — пустить поток, от центра — остановить. Свайп по центру — открыть пару направлений.
- Совместимые потоки (север + юг, запад + восток) можно пускать вместе. Если пустить конфликтующие — спокойные водители уступают (растёт хаос), нетерпеливые рискуют (возможна авария).
- Тап по машине — информация и команды: «Пропустить», «В объезд», «Эвакуировать», «Свисток».
- Инструменты: свисток (перезарядка), дзен (успокоить направление), сирена и пончик (раз за смену).
- Поражение: лимит ошибок, максимальный дорожный хаос, лопнувшее терпение или истёкшее время.

## Режимы
Карьера (6 районов × 3 уровня), бесконечная смена, испытания, смена дня, ежедневные задания, серия входов, достижения, репутация районов. Магазин — только косметика.

## Структура
- `src/config/` — данные: транспорт и характеры, карты, районы и уровни, события, экономика, предметы, тексты
- `src/sim/` — правила без графики: граф дорог, ConflictResolver, симуляция смены, фиксированный шаг, RNG
- `src/render/` — 3D-сцена (Three.js) и процедурные low-poly модели
- `src/ui/` — контроллер смены (ввод, HUD, 2D-слой) и звук
- `src/meta/` — сохранения (версия, миграция, контрольная сумма) и прогрессия
- `src/app/` — экраны: город, магазин, гардероб, настройки, профиль
- `tests/` — тесты (`npm test`)
- `android/`, `ios/` — проекты Capacitor

## Команды
```
npm install
npm run dev            # игра в браузере
npm test               # тесты
npm run build          # сборка в build/web
npm run android:apk    # APK (нужен Android SDK, путь в android/local.properties)
```

## iOS
Проект `ios/` (Capacitor, Swift Package Manager) создаётся и обновляется командой `npx cap sync ios`.
Собрать `.ipa` можно только на Mac с Xcode: открыть `ios/App/App.xcodeproj`, выбрать команду разработчика и запустить на устройстве.
